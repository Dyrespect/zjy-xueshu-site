## delivery（8）

- `GET /api/delivery/{token}` — View
- `POST /api/delivery/{token}/feedback` — Feedback
- `GET /api/delivery/{token}/final/{file_id}` — 下载最终版：每次都重新查订单是否已完成（不靠前端藏按钮）；只给 deliverables_for_customer 里的最终版。
- `POST /api/delivery/{token}/platform-confirmed` — 平台单客人说「我已经在平台点了确认收货」：只通知负责人去核对（6 小时内只通知一次），订单不动。

- `POST /api/delivery/{token}/received` — 确认收货（confirm.receipt，source=customer）：自有渠道才算；成了同一请求里放出最终版。
- `POST /api/delivery/{token}/revision` — 逐页提修改：items = [{page, text, files: [下标]}]（page 空 = 整体意见）；只给一段话也行（text）。
- `POST /api/delivery/{token}/viewed` — 客人看了几页（每版每天记一次，申诉举证用）。
